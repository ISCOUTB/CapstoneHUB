# Ejecutanto por separado

# backend

```bash
npx prisma generate
npx prisma migrate dev --name [name]
npm start dev
```

ir a [https://localhost:3001/api](https://localhost:3001/api)

# frontend

```bash
npm run dev
``` 
ir a [http://localhost:3000](http://localhost:3000)
